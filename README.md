# NatLens 🐾

A cross-platform mobile application that makes
zoo visits more interactive and educational.

## Features
- Animal discovery and identification
- Digital ZooDex collection
- Educational missions and achievements
- Token-based rewards and redemption
- Zoo map and animal recommendations
- Staff content management

## Tech Stack
- React Native
- Expo
- TypeScript
